# HORIZON — интерфейсы после меню

Открытая лаборатория UI/UX веб-приложений на горизонте **2030–2035**. Не предсказание дизайна будущего, не чат-бот с декоративными карточками. Работающий эксперимент: **намерение → подходящие инструменты → проверка конкретных изменений → применение → отмена**.

**MIT · TypeScript · Web Components · IndexedDB · ноль runtime-зависимостей · без платных API**

## Запустить

Нужны Node.js 22+ и npm. После клонирования:

```sh
npm install --ignore-scripts
npm run dev
```

Открыть `http://localhost:4173`. Это простой сервер без hot reload: после изменения исходников повторите `npm run build` и обновите страницу. TypeScript зафиксирован на 5.8.3 — это проверенная версия сборки, не заявление о самой новой версии языка.

```sh
npm run check               # строгая проверка типов, сборка, 16 доменных тестов
npm run build               # статический сайт в dist/
npm run preview             # сервер уже собранного dist/
```

После сборки **`dist/horizon-standalone.html`** — приложение в одном файле. Сохраните и откройте в браузере: установка Node для самого HTML не нужна. При запрете IndexedDB приложение явно переходит в память; перед закрытием экспортируйте JSON. Профили браузеров и поведение `file://` различаются.

Для размещения загрузите содержимое `dist/` на статический HTTPS-хостинг. Публичный сервер или платный аккаунт для эксперимента не требуются. Репозиторий сам по себе не означает включённый GitHub Pages.

## Попробовать за две минуты

1. Нажмите **«Запуск за 4 недели»**. Появятся план, бюджет и ограничения; проект пока не изменился.
2. Снимите отметку **«Бюджет»**, примените остальные изменения, затем нажмите **«Отменить последнее»**. Экспорт всегда содержит только применённое состояние, не черновик.
3. Переключитесь на **«Разобрать бюджет»** или **«Только важное»**. Закрепите состав модулей: последующие запросы больше не будут перестраивать его. Откройте **«Вручную»** — тот же результат доступен без командной строки.

**Ctrl/⌘ K** открывает команды, **Ctrl/⌘ Enter** отправляет запрос, **Esc** закрывает диалог. На телефоне к проверке ведёт закреплённая нижняя панель. Импорт JSON находится в командах и тоже требует проверки перед применением.

## Что действительно работает

- Каталог проверенных компонентов: план, бюджет, ограничения. Типизированная модель отделена от рендера.
- Предварительный просмотр, выбор отдельных изменений, явное подтверждение, журнал, ограниченный стек отмены.
- Ручной путь, закрепление состава, режим фокуса, клавиатура и сенсорный ввод.
- Валидация ввода и импорта, экранирование пользовательского текста, отклонение неизвестных действий и устаревших предложений.
- IndexedDB с атомарной проверкой ревизии против тихой перезаписи другой вкладкой; явный режим памяти при недоступности хранилища.
- Локальные JSON-экспорт/импорт. Service worker для повторного открытия статического сайта без сети; переносимый HTML не требует service worker.
- Раздел **«На чём основано»**: семь первоисточников, отдельно факт, наш вывод, ограничение и реализация.
- Раздел **«Проверить самому»**: два пути одинаковой задачи, измеренные время, активации кнопок и ошибки, выгрузка результатов. Это проба на одном человеке, не доказательство превосходства метода.

## Чего здесь нет

**LLM отсутствует.** Запросы обрабатывает ограниченный движок правил с тремя сценариями: запуск, бюджет, фокус. Неизвестный запрос отклоняется, а не имитирует понимание. Все суммы, пропорции и сроки — учебные данные; это не финансовые рекомендации и не оценка реального производственного плана.

Нет настоящего агента, публикации, платежей, внешней отправки, микрофона, камеры, синхронизации, авторизации, шифрования или совместного редактирования. A2UI и WebMCP обсуждаются как основания архитектуры, **их протоколы не реализованы**. Данные браузера могут быть удалены; экспорт нужен для резервного копирования. При импорте нельзя выполнить код из JSON.

Ни один источник не доказывает, что к 2035 году все интерфейсы станут такими. Цвета и типографика HORIZON — авторское решение, не результат научного прогноза.

## Почему этот стек

Это маленькое интерактивное приложение, не поисковый портал и не масштабная совместная среда. Нативные ESM и Web Components дают переносимый HTML без сервера и runtime-зависимостей. TypeScript проверяет контракты; чистая доменная модель не знает о DOM; IndexedDB отвечает за локальные транзакции. Семантический HTML и CSS позволяют обычное управление и прогрессивные улучшения.

React, Vite или серверный фреймворк не являются «устаревшими». Здесь их дополнительная инфраструктура не нужна. С ростом приложения можно заменить слой рендера, сохранив модель предложений и действий. Это выбор под эксперимент, **не прогноз победителя фреймворков 2035 года**.

## Проверки и ограничения качества

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python tests/browser.py
```

Тест сам поднимает сервер на порту 4181. Полный режим проверяет IndexedDB после перезагрузки, offline reload и конфликт вкладок. `python tests/browser.py --inline` проверяет переносимый HTML через `set_content` при запрещённой браузерной навигации: он намеренно проверяет режим памяти, **не IndexedDB и не service worker**.

Локально при создании прошли строгая проверка TypeScript, **16 доменных тестов и 21 браузерная проверка** в Chromium 144, inline-режим; ширины 320, 390, 1024 и 1536 px. В основном сценарии не было внешних HTTP-запросов и ошибок JavaScript. Статус полного HTTP-прогона смотрите в Actions, а не выводите из inline-теста.

Скринридеры, Safari, Firefox и полный аудит WCAG/axe не проверялись. Не заявляется сертификация доступности или готовность к хранению чувствительных данных. Подробнее: [архитектура](docs/ARCHITECTURE.md), [проверка гипотез](docs/STUDY.md), [границы QA](docs/QA.md).
