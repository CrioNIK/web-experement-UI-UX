# Проверки сборки 0.1

На момент создания: Node 22.16.0, TypeScript 5.8.3, Chromium 144, Python Playwright 1.57.0.

## Локально выполнено

- `npm run typecheck`: strict TypeScript, без ошибок.
- `npm test`: 16 доменных тестов, 16 прошли.
- `HORIZON_CHROMIUM=/usr/bin/chromium python tests/browser.py --inline`: 21 проверка прошла.
- Реально проверены: запуск; постоянное предупреждение memory fallback; отклонение неизвестного запроса; отсутствие мутации при preview; выборочное применение; отмена и журнал; ручной путь; инертный HTML в пользовательском тексте; клавиатурный диалог; закрепление модулей; подтверждение готовности задачи; безопасный импорт; источники; два пути измерения; режим фокуса; отсутствие внешних запросов и ошибок JS в проверенном пути; отсутствие горизонтального переполнения на 320, 390, 1024, 1536 px.

Браузер в среде создания запрещал навигацию на localhost и file:// политикой администратора. Использован `page.set_content` с переносимым HTML. Этот реальный fallback обнаружил и помог исправить зависимость журнала от `crypto.randomUUID`, недоступного в данном контексте. Режим хранения в памяти проверялся без подмены IndexedDB.

## Визуальная проверка

Открыты реальные PNG desktop/mobile после рендера. Проверены текст и отсутствие имитации LLM, постоянная навигация, граница preview/apply, сочетание шрифтов и контраст вспомогательного текста, пропорции плана/бюджета/проверки, мобильный перенос и доступ к review. Добавлена мобильная нижняя панель перехода к проверке; исправлены бледные подписи и слишком мелкая вспомогательная типографика.

ImageGen-концепта или отдельно утверждённого пользователем макета не было. Поэтому совпадение с таким макетом не заявляется. Палитра и компоновка — проектное решение, не исследовательский вывод.

## Не следует выводить из этих проверок

Inline-режим **не проверяет** IndexedDB после reload, offline reload service worker или конфликт вкладок. Для этого есть полный HTTP-режим `python tests/browser.py` и workflow. Его фактический результат доступен в Actions и артефакте `browser-report.json`; наличие теста не означает его прохождение.

Не выполнены полный аудит WCAG/axe, тестирование скринридерами, Firefox/Safari и работа на физическом мобильном устройстве. Тесты viewport в Chromium не заменяют последние. Нет проверки реального LLM или внешних действий, потому что их нет в реализации.
